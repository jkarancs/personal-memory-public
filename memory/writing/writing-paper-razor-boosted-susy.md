"Inclusive search for supersymmetry in pp collisions at sqrt(s)=13 TeV using razor variables and
boosted object identification in zero and one lepton final states" - JHEP 1903 (2019) 031.
https://inspirehep.net/literature/1709318

The main part of my doctoral studies. I provided the majority of code for the boosted analysis: all plots, calculations, and tables for that part, which achieved the best Run 2 exclusion limits in two simplified models for a period of time.
