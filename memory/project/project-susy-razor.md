A Supersymmetry search using razor kinematic variables and boosted-object techniques on 2016 LHC data (JHEP 1903 (2019) 031) - the central analysis of my doctoral studies and the basis of my PhD thesis. I was responsible for writing the majority of the analysis software: coding, plotting, and statistical inference, carried out in the BoostAnalyzer17 framework. It set the best 2016 exclusion limits in two simplified models and is part of the body of work later recognised by the 2025 Breakthrough Prize in Fundamental Physics. Primary repository: [BoostAnalyzer17](https://github.com/jkarancs/BoostAnalyzer17) (with BoostedRazorAnalysis and B2GTTrees). The code is still being used by my co-contributor, Sezen Sekmen: [ssekmen/BoostAnalyzer17](https://github.com/ssekmen/BoostAnalyzer17) for which I'm proud of.
