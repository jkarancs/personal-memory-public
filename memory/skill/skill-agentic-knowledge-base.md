Designed a structured agentic knowledge base (AGENTS.md, RULES.md, repository maps, architecture and domain summaries, reusable tools and skills) used across ~50 repositories. Core principle: AI should navigate curated knowledge, not re-scan code - teaching agents what NOT to load is often more valuable than a bigger context window. Result: lower token usage, better architectural consistency, and much larger cross-repository tasks.
